## Delivered architecture and journeys

- Schema 1 remains readable; schema 2 adds matching, sequencing, accepted-text blanks, integer number lines, equal-part fractions and four-place manipulation. ActivityRules validates and marks on the server. ActivityComposer provides named authoring controls, bounded previews and format-specific teaching examples. The fixed renderer runs both online and offline without author/model scripts. Sequencing options are authored in correct order; blanks accept 1-6 explicit equivalents, not quiz distractors.
- A question bank references one immutable published activity (up to 10 questions or a mathematics exercise). Teaching staff can reuse it within their organisation; there is no silent migration of old attempts to new answer keys. Teachers add published resources from the resource page, learners submit explicitly online, and authorized staff review names/counts/best results. Three new assessment permissions are appended to reference data without changing existing permission IDs. Teacher/HeadTeacher/ProjectManager delegation remains valid. Own history/deletion, payload-bound idempotency, 365-day expiry and bounded physical cleanup are implemented. Limits and the formative-assessment boundary are in [the privacy/offline design](sprint-2-privacy-and-offline.md).
- ContentGeneration reuses the existing durable LessonGenerationJobs table, global processing slot, cancellation/watch/lease recovery, trusted worker identity, organisation AI approval and shared usage ledger. A typed purpose distinguishes content jobs from lesson proposals. Only authoritative curriculum context/language/instructions enter content inference; lesson identity, teacher/school metadata and learner records do not. The configured Ollama/OpenAI adapters use strict declarative schemas and bounded responses. No ambiguous calls are retried or refunded. Model/provider/lesson revision provenance is server-owned; accepted activity assets record the originating job in audit correlation. Independent approval remains mandatory. Storyboards are reviewable text plans, not executable animation assets.
- Complete offline packages use the published lesson revision, attached published/downloadable library assets and SHA-256 manifest versions. A bounded IndexedDB media cache supports ranged retry, integrity checks, quota errors and explicit cleanup. The final manifest is rechecked before export. External/uploaded references and unsupported/oversized assets fail closed instead of being omitted. Exported HTML embeds verified media and the fixed activity renderer; it contains no session data or learner persistence. Existing registered-device sync remains intact; its new progress-policy read explicitly reports disabled.
- Grade-first discovery spans active curricula/versions, presents names with parent context and continues through the existing dependent selectors. Teachers can also search their draft lessons from a published resource, attach it to the existing source list and open Source Explorer for explicit selection/review. Sidebar navigation now exposes assessments only to authorized users.

## Verification and performance

Local integration: the full PostgreSQL-enabled backend suite passed 319 tests with zero skips, including provider transport/privacy and single-answer checks. Frontend lint/type checking, 59 tests and the production build passed. All 47 real Chromium workflows passed, including every activity online/offline, learner submissions and teacher summaries, AI proposal acceptance, resource assignment and interrupted-range recovery. Resource-text inclusion and unknown-field rejection received a final focused rerun. Fresh NuGet direct/transitive and frontend audits reported no known vulnerabilities; EF found no model drift and generated idempotent migration SQL. Final pushed-head CI evidence is recorded in the completion handoff; local runs alone do not validate the Linux container gates.

No live-model inference acceleration is claimed. A controlled eight-second generation fixture acknowledged in 160 ms during the complete browser run; this measures background responsiveness, not model speed or quality. The new content path sends bounded curriculum-only context and shares the existing inference slot/budgets. Representative educator-scored local-language/cold/warm/provider benchmarks remain a release gate. Offline range transfers use 1 MiB chunks, 25 MiB packages and a 50 MiB temporary media budget; this is a bounded implementation, not a throughput benchmark.

## Remaining limits and release gates

This sprint provides complete formative journeys, not a high-stakes examination platform. Banks reuse whole immutable activities; cross-resource question composition, per-class assignment scheduling, richer analytics and unlimited-history browsing are future work. Initial views are bounded to 100 banks/learners/latest own attempts. Place-value exercises use canonical digits; carrying/regrouping, improper fractions, arbitrary number-line ranges and richer storyboard production are outside this slice.

Production acceptance still needs real approved-provider output quality, educator review across grades/languages, manual keyboard/screen-reader/tablet/classroom checks, an operator-approved online retention notice, and secure handling of exported teaching material. Offline exports cannot enforce revocation or encrypt themselves. Identifiable offline progress remains deliberately disabled until the policies in the privacy/offline design are explicitly approved. Nothing has been merged or deployed automatically.

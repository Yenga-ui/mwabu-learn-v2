# Lesson Journey teacher guide

Use the lesson library to search titles or expand **Find lessons by grade, subject, term or topic**. Start with a grade or follow the existing curriculum hierarchy. Results retain organisation visibility and historical curriculum relationships, and are ordered by most recently updated. Open **Lesson Journey** from a lesson card, or **Prepare Lesson Journey** from the saved editor. The editor saves pending plan edits before opening preparation.

Preparation shows the saved revision, curriculum context, objectives, step timeline, timing and readiness guidance. Older lesson plans map teaching sections into private preparation instructions. They do not automatically project planning prose or suggested answers. Add learner-facing explanations explicitly and save the preparation. A valid step can still be taught without optional text or media.

Select a step to edit its title, phase, mapped plan section, minutes, teacher instructions, learner-facing explanation, hint, answer and private notes. Phases are editable names, not a prescribed teaching method. Add, remove or move steps without recreating the plan as slides. Save creates another immutable lesson revision. Leaving with unsaved preparation offers **Keep preparing** or **Discard edits and leave**; reload/close also warns. Revision conflicts preserve the local edits and display the server error: keep the view open and compare with the lesson's latest revision before reapplying changes.

Search approved resources within the current step. Choose a resource, attach a specific file and preview it immediately. Move attachments earlier or remove them. To replace one, remove the old attachment and select the reviewed replacement. Attachments preserve the exact immutable asset and checksum. A revoked, deleted or unpublished version shows an error; playback does not substitute a new primary asset. Save validation rejects invalid versions. Media starts under teacher control. Review image alternatives, captions, language, file size and classroom suitability before teaching. Source Explorer and governed AI content generation remain available from **Edit lesson plan**; only approved published library assets can be attached to steps.

Choose **Teach Lesson** after saving. This opens the same saved revision in a clean learner-facing screen. It never renders private teacher instructions, notes, school metadata, author identity, learner records or administration panels. Use **Print private teacher guide** in preparation if you need custom step instructions and notes while mirroring; do not display that guide to the class. The existing Ministry lesson PDF/print export is also preserved. Exiting to preparation is an explicit transition out of the projection-safe view, so stop mirroring before opening private guidance. An older valid lesson can open a safe objectives/step outline without optional preparation; its planning bodies and suggested answers are not automatically projected.

Use previous/next, the lesson overview or keyboard arrows on the slide heading/background. Arrow keys are not captured inside activities or media controls. Select a linked resource without leaving the lesson. Step hints and answers remain absent until revealed and reset when you change steps. Start, pause and reset the step timer as needed. Fullscreen uses the browser's supported capability and falls back to the normal teaching view if unavailable. **Finish lesson** returns to the library. Portrait preparation and landscape teaching are responsive; change orientation using device controls. The website does not force casting or orientation.

Whole-class activities follow **Ask → Discuss → Reveal → Explain**. Manipulate answers, number lines, equal fraction parts and place values while the class observes. Reveal the answer explicitly, then show the explanation. Reset the demonstration or move between questions. Existing animation pause/restart/speed controls remain available. No learner login, score, attendance inference or progress upload is created by this mode. Individual learner assessments remain separate.

For offline use, first complete independent lesson review/publication, then open **Complete offline lesson package** in the lesson editor. Review the personal-data notice and download. The published revision and exact step resources are bundled, verified and checked again before export. Interrupted media transfers resume through the existing bounded cache. Offline teaching supports step selection, navigation, controlled hints/answers, fixed whole-class activities and embedded media with no network requests. Private step guidance and session data are omitted. Retain access-controlled backups and remove obsolete exports: portable HTML cannot enforce subsequent revocation or protect itself with device encryption.
